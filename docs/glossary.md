# ユビキタス言語定義

## 撮影用ポスト画面メーカー(X版)

> **ステータス:** ドラフト v0.1
> **最終更新:** 2026-08-01

---

## 1. ドメイン用語の定義

| 用語 | 定義 |
|---|---|
| プロジェクト(Project) | 1つの作品(映画・ドラマ・演劇など)に対応する管理単位。複数の「画面(Scene)」を持つ |
| 画面(Scene) | プロジェクト内で作成する1つのフェイク画面。種類(タイムライン/投稿詳細/プロフィール/DM)を1つ持つ |
| 種類(Scene Type) | 画面がどの種類のX画面を模したものかを表す区分。`timeline` / `post_detail` / `profile` / `dm` の4種(フェーズにより有効な種類が異なる) |
| アカウント(Account) | 画面内に登場する投稿者の情報(表示名・ユーザー名・アイコン・認証バッジ有無)。Sceneに従属する |
| 投稿(Post) | アカウントが投稿した1件分の内容。本文・いいね数・リポスト数・返信数・日時を持つ |
| 引用ポスト(Quoted Post) | ある投稿が別の投稿を引用して表示する構造。投稿詳細エディタで対応する |
| ステータスバー設定(StatusBarConfig) | 画面上部に表示する時刻・電波・電池等の疑似ステータスバーの設定。Sceneに1つ紐づく |
| フィード型 | 投稿にいいね・リポスト・コメントがぶら下がる画面構造。タイムライン・投稿詳細・プロフィールが該当する |
| チャット型 | 吹き出しが並ぶ画面構造。DM(フェーズ3)が該当する。LINE版に近い構造 |
| テンプレート先行方式 | 新規Scene作成時に先に「種類」を選ばせ、以降はその種類専用の編集画面のみを表示する操作方式 |

---

## 2. ビジネス用語の定義

| 用語 | 定義 |
|---|---|
| フリーミアム | 核となる機能を無料で提供し、追加機能のみ課金対象とする収益化モデル。本プロダクトの基本方針 |
| 買い切り | サブスクリプションではなく、1回の支払いで機能を永続利用できる課金方式 |
| ウォーターマーク(透かし) | 無料版であることを示すために画面に重ねる印。本プロダクトでは撮影に映り込むため無料版でも一切使用しない方針 |
| フェーズ1 / フェーズ2 / フェーズ3 | 機能リリースの段階区分。フェーズ1=MVP(タイムライン・投稿詳細)、フェーズ2=プロフィール、フェーズ3=DM |
| 有料転換率 | 無料利用者のうち買い切り課金に至った割合。KPIの一つ |

## 3. UI/UX用語の定義

| 用語 | 定義 |
|---|---|
| タイムライン画面 | 複数の投稿が縦に並ぶフィード表示画面 |
| 投稿詳細画面 | 1つの投稿をドアップで表示する画面 |
| プロフィール画面(フェーズ2) | アカウントのプロフィール・フォロワー数・投稿一覧を表示する画面 |
| DM画面(フェーズ3) | ダイレクトメッセージのトーク(チャット)画面 |
| フルスクリーン表示モード | OSのステータスバー・ホームバー・通知を隠し、アプリ描画のみを全画面に表示する撮影用モード |
| 疑似ステータスバー(FakeStatusBar) | OS実機のステータスバーの代わりにアプリが描画する、時刻・電波・電池を表す部品。iPhone風/Android風を切り替え可能 |
| 認証バッジ | アカウント名の横に表示する、公式認証を模した印(チェックマーク等) |
| 数値ラベル表記 | いいね数・リポスト数などの表示文字列。「1.2万」のような省略表記を自由に入力できる |
